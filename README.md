# 中西區照顧導航

以生活情境協助中西區居民與高齡家庭查找照顧資源。

## 查詢功能

- 單一情境開啟結果頁；多項需求整理建議步驟及聯絡順序。
- 依類型、所在地與關鍵字搜尋；同一院所可同時具備醫療及疫苗標籤。
- 有地址者提供地圖導航；只有名稱的名冊資料提供名稱搜尋並明示資料未齊。
- 電話、活動時間、服務分區與來源依資料呈現。

## 資料更新

115年11月25日資源統整清單：592筆名冊與服務資料，另有12項官方與常用入口。39筆疫苗服務標示已合併到院所或衛生所資料，未重複加計。名冊筆數不是轄區全部機構數，也不是已取得服務的人數。

資料來源日期記錄於 `local-resources.js`，查詢功能由 `app.js` 共用。原始聯絡人姓名及其他內部欄位不列於網站。更新資料後，首頁與結果頁的程式版本須一併更新，以避免手機沿用快取。

## 生活情境擴充（115.11.26）
首頁共12個情境入口（含洗澡分流），複選由6項擴充為10項。新增疫苗、輔具與居家改善、接送、活動共餐與課程。
scenario-data.js集中情境內容；結果頁依同一資源名冊顯示對應窗口、地區篩選與完整分類連結。
複選依需求組合提供聯絡順序：疫苗＋接送先確認院所時間；輔具＋福利合併詢問評估與費用；照顧或喘息與輔具／交通優先由原長照窗口一起討論；社區活動與替代照顧分別確認。
接送與輔具程序核對臺中市衛生局、社會局官方說明；不以網站判定個人資格或保證服務名額。
